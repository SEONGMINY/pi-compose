# Pi Compose ADE — Orca 참조 기반 UX 재구성

기준: 실제 사용자가 제공한 Orca/현 Pi Compose 화면. Main Agent 컨텍스트 보존, Work Agent의 정확한 Fork, Support Agent의 독립 대화를 유지한다.

## 화면에서 무엇을 먼저 보여주나

1. 프로젝트: 왼쪽 목록에서 Git 프로젝트를 찾는다.
2. Main Agent: 프로젝트 아래에 설계·의사결정 단위로 여러 개 존재한다. 기능 또는 제품 단위.
3. Work/Support: 각 Main 아래 실제 작업. Work는 Fork 관계이고 Support는 업무상 연관 관계다.
4. 터미널: 실제 Pi TUI는 탭과 드래그 분할로 표시한다. 숨김은 프로세스 종료가 아니다.
5. 변경 검토: 터미널을 유지하고 오른쪽에 Git 파일 목록과 파일별 Diff를 보여준다.

Orca의 프로젝트 목록, 작업 카드, 에이전트 행, 상단 탭, 파일 탐색·Diff 경험을 참고한다. Orca의 전 기능 또는 계정 시스템 자체를 복제하는 것은 아니다.

## 고품질 맥락을 어디에서 확인하나?

Main Agent의 맥락 → 핵심 맥락에는 사용자가 명시적으로 표시한 '결정'과 '반드시 지킬 제약'을 보여준다. 이 목록은 자동 AI 요약이 아니다.

맥락 → 원본 대화에서 실제 Pi 세션 메시지를 확인하고 결정/제약 표시를 한다. ADE에는 Pi 메시지 entry ID와 표시 종류만 저장한다. 원문은 Pi JSONL에서 다시 읽는다.

Work Agent의 맥락 → 핵심 맥락:
- 원본 Main 이름, 원본 Pi JSONL 경로
- Fork 당시 마지막 기록 ID
- Work 세션 헤더의 원본 세션 경로 일치 여부
- Work 활성 대화에 분기 시점 기록이 존재하는지
- 원본에서 표시한 결정 중 실제 상속된 항목 / Fork 이후 Main에서 표시돼 Work에 없는 항목

**기록의 계보를 확인한 것이 모델의 의미 이해나 구현 품질을 보증하지 않는다.** 코드 검토가 별도로 필요하다.

Support Agent는 독립 Pi 세션이다. Main 아래 표시되더라도 대화 내용을 상속하지 않는다.

## 변경을 눌렀을 때

- 실제 Git 파일 목록과 변경 유형을 먼저 보여주고, 파일 선택 후 줄별 추가·삭제를 제공한다.
- Git 기준 커밋을 표시하며, 작은 미추적 텍스트 파일은 미리보기를 제공한다.
- 변경 파일 없음/실패 시 이유와 다음 행동(새로고침/터미널 확인)을 보여준다.
- 공유 폴더의 Git 변경은 특정 Agent가 작성했다고 표시하지 않는다.
- Diff 검토는 구현 완료·계약 준수 또는 Git 병합을 뜻하지 않는다.

## 로그인

- Pi의 공식 ModelRuntime과 인증 저장소를 그대로 사용한다.
- Pi 로그인 명령의 OpenAI 브라우저 인증 및 기기 코드 인증 중 선택한다.
- 진행 중/연결됨/오류/취소 상태를 구분하고 코드 입력을 지원한다.
- 현재 ADE 계정 화면은 OpenAI만 지원한다. 다른 모델 공급자의 인증 UI는 미구현이다.

## 예측 가능한 동작

| 행동 | 예상 결과 |
| --- | --- |
| Main 선택 | 원본 Main 터미널, 그와 관련된 작업 표시 |
| Work 생성 | 정확한 Main 저장 세션 Fork; 확인 실패 시 잘못된 세션으로 대체하지 않음 |
| Support 생성 | 독립 Pi 대화로 시작 |
| Agent 탭 전환 | 기존 Pi 프로세스와 대화 유지, 화면 이동 |
| 맥락 보기 | 원본 기록과 결정/제약·출처 확인, 자동 요약 아님 |
| 변경 누르기 | 오른쪽 Git 변경 열림, 터미널 유지 |
| 변경 없음 | 이유와 다시 확인하는 방법 표시 |
| 로그인 취소 | Pi 인증 요청 중단 |

## macOS 실행

    git fetch origin
    git switch feat/ade-orca-workspace-context-review
    npm install
    npm run ade:dev

CI 검증 범위: macOS 의존성 설치, TypeScript 검사, JS 구문, Ghostty 번들 빌드.

미검증: 실제 UI의 Orca 시각적 동등성, macOS Ghostty/한글 입력, OAuth 인증, 모델 기반 Fork→코드 변경→검토 E2E.

이후 고도화: Orca의 고급 파일 편집, 자동 요약, 인라인 Diff 의견, 다양한 로그인 공급자. 핵심 컨텍스트 보존과 별개로 우선순위를 판단한다.
