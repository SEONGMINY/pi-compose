# Problem Statements — 사용자 발화

> 상태: 초기 문제 기록 · 2026-11-10
>
> 현재 근거는 **프로젝트 제작자 한 명의 발화**입니다. 다른 고객의 직접 인터뷰나 보편적 고객 요구로 일반화하지 않습니다. 원문은 그대로 유지하며 원인·기능·해결책을 덧붙이지 않습니다.
>
> **상태 기준:** `현재 확인 필요` = 최신 구현에서 재현 여부 미확인, `과거 경험` = 해당 시점 UX가 이후 바뀜, `인접 경험` = Pi Compose 제품 자체가 아닌 개발 대화에서 나온 문제.

## P-01 · 세션이 바뀔 때 배경을 다시 전달해야 함

> “새로운 세션에서 계속 이어서 진행하고 싶습니다. 맥락 잃지 않고 진행할 수 있게 최대한 디테일하게 프롬프트 작성해주세요.”

- 출처: 2026-11-06 프로젝트 개발 대화
- 상태: **인접 경험** — Pi Compose의 현재 세션 복구 문제로 직접 검증한 발화는 아님

## P-02 · Work 완료 결과의 도착을 알아차리기 어려움

> “잠깐 저거 검증하기 전에 왜 작업 완료됐는데 main으로 전달하거나 overlay가 발생하지 않아?”

- 출처: 2026-11-02 실사용 피드백
- 상태: **과거 경험** — 당시 Overlay 중심 UX가 이후 폐기됨; 새로운 방식의 해결 여부는 미확인

## P-03 · 시작 과정이 기대한 작업 흐름과 다름

> “오버뷰를 열고 그 이후에 메인 에이전트를 붙이는게 이상합니다.”

- 출처: 2026-11-02 실사용 피드백
- 상태: **과거 경험** — 해당 Overview 설계는 이후 폐기됨

## P-04 · Handoff 질문이 나타나지 않음

> “ask_user 가 나타나지 않습니다.”

- 출처: 2026-11-09 실사용 피드백
- 상태: **현재 확인 필요** — 당시 후보 생성 및 질문 흐름의 오류를 조사했으나 최신 UX에서 재검증되지 않음

## P-05 · 전달을 시작해도 후보가 표시되지 않음

> “/intercom 했을 때 다른곳도 많이 나는데 < 했을 때 아무것도 나타나지 않습니다. 왜 >w @... 처럼 했을 때 연관검색어 처럼 나오지 않나요?”

- 출처: 2026-11-06 실사용 피드백
- 상태: **과거 경험** — 기존 수신자 자동완성 설계에서 관찰; 최신 버전의 재현 여부 미확인

## P-06 · 개발 과정의 사용성이 불편함

> “지금 사용방식이 말도 안됩니다. 거이 프로덕트에 사용할 수 없는 정도입니다.”

- 출처: 2026-11-10 실사용 피드백
- 상태: **현재 확인 필요** — 어느 단계를 재현할지 추가 관찰 필요
